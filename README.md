# Hybrid-Analog-Computer
A reconfigurable hybrid analog computing platform (PCB board) using op-amp based integrators, summers, and scaling circuits to simulate nonlinear dynamical and chaotic systems in real time.

Analog computers enable real-time solution of dynamic differential equations using continuous-time signals. In The Breadboard V1, a basic
analog computing block consisting of integrators and summing amplifiers is implemented on a breadboard to validate functionality.

In Hybrid Analog Board V2, this initial prototype is transformed into a robust and scalable hardware platform through the design and implementation of a custom PCB board. The transition from breadboard to PCB enables improved signal integrity, structured layout, and reliable operation. In addition to hardware refinement, the system is extended with digital interfacing for parameter monitoring, allowing better configurability and repeatability. This work focuses on improving the physical implementation of the analog computer and extending it with digital support to improve control and usability.
